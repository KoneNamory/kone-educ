Notifications par e-mail

…

Chaque notification du site (nouveau cours, facture, paiement confirmé, message…) est aussi envoyée par e-mail, gratuitement grâce à Brevo (300 e-mails par jour offerts).

📘 Comment l’activer (5 minutes, gratuit)
  1. Créez un compte gratuit sur brevo.com.
  2. Menu Expéditeurs, domaines et IP dédiées → Expéditeurs → ajoutez votre adresse (ex. votre Gmail) et validez le code reçu par e-mail.
  3. Menu SMTP et API → onglet Clés API → Générer une nouvelle clé → copiez-la.
  4. Collez la clé et l’adresse validée ci-dessous, puis cliquez sur « Enregistrer ».

Sécurité et sauvegarde

L’export télécharge une copie complète (comptes, demandes, dossiers, factures, comptes rendus, journal…) à conserver en lieu sûr. Une sauvegarde automatique chiffrée est aussi faite chaque semaine.
